# **App Name**: CodeConnect

## Core Features:

- Community Showcase: Showcase members of the Telkom University and Mercu Buana communities. Include personal projects and member profiles.
- Event Calendar: Display upcoming events, workshops, and hackathons for Codebusters, with clear indication of events co-organized with Mercu Buana.
- Resource Library: A searchable database of coding resources, tutorials, and project documentation.
- Collaborative Project Board: A platform for suggesting, planning, and organizing collaborative projects between Telkom University and Mercu Buana members.
- AI-Powered Idea Generator: Generate project ideas using the tool, considering the skills and interests of community members. Integrates coding challenge suggestions based on the community member skill level.

## Style Guidelines:

- Primary color: Maroon (#B6252A) to represent Telkom University's spirit and exploration, with a secondary bright red (#ED1E28).
- Background color: Light gray (#F0F0F0), providing a clean and modern backdrop to ensure readability.
- Accent color: Use a muted blue (#4682B4) inspired by Mercu Buana's colors, integrated subtly to highlight collaborative sections or partner logos.
- Headline font: 'Space Grotesk' sans-serif for a tech-forward, digital feel. Body font: 'Poppins' for clean and accessible reading.
- Utilize clean, line-based icons inspired by digital elements such as code snippets, circuit boards, and data flows.
- Employ a grid-based layout with clear sections for easy navigation and content prioritization, emphasizing key areas like projects and events.
- Incorporate subtle transitions and loading animations that mimic data flow, providing a dynamic user experience without being distracting.
